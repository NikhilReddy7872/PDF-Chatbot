### PDF-Chatbot
📄 PDF Chatbot (Work in Progress)

A web-based PDF chatbot that allows users to upload a document and ask questions based on its content using Google’s Gemini API.
This project focuses on building an interactive document-based AI assistant directly in the browser.

✨ Current Features

Upload and read PDF files in-browser

Extract text using PDF.js

Ask questions based on PDF content

AI-powered answers using Google Gemini

Clean chat-style interface

Session-based API key handling

🛠️ Tech Stack

HTML, Tailwind CSS, JavaScript

PDF.js for PDF parsing

Google Gemini API

Session Storage

🚧 Project Status

⚠️ Under Development

Planned improvements:

Better context handling for large PDFs

Chunking & embeddings for accuracy

Improved error handling

UI refinements

Conversation memory

Performance optimization

🎯 Goal

To build a lightweight, browser-based PDF assistant that helps users quickly understand documents without external tools or uploads.
